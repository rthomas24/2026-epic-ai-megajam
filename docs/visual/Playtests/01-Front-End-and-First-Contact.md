# Front end and Act 1 — First Contact

Use a Windows build from main. Record the commit, package name, resolution, input device and save state in the run log. Allow about 20–30 minutes for a first run and a second boundary crossing, plus restart time. This is a tester estimate. Record actual elapsed time. Use a separate, fresh save profile for the first-play check. Preserve the player's existing saves.

| Step | What to do | What to see or hear |
|---|---|---|
| 1. Cold boot | Start the game at the normal menu. Open Settings, lower Music, return with Esc or pad B and reopen Settings. | A single menu track responds to Music volume. Settings keeps the value and visible focus. Continue reflects the fresh profile. Take a menu screenshot and record whether pad input was physical or simulated. |
| 2. First New Game | Choose difficulty and play the opening without skipping. Record game audio and picture from before the final intro shots through the first controllable frame. | No offer to skip the tutorial on a first play. The opening runs about 49 seconds. Wren/Rift, Kato/Lancer and Moss/Bastion remain identifiable during their cards. Subtitles remain readable against the sky. The interrupted warning O_Unknown_Dont stays anonymous. Log any missing performance separately from its subtitle. |
| 3. Control handoff | Move the ship as control returns. Mark the first frame with player input and the heard downbeat. Keep recording through a complete loop. | The intro gives way to the same battle without a load or fade to black. Ethereal Pulse reaches source 0:38 on control and repeats 0:38–1:35. Compare the audible onset against the frame; a clock log alone cannot establish sync. Menu music has stopped. |
| 4. Learn the squad | Evade the first volley, then target and fire. Switch ships and use their available signature powers. | EVASIVE MANEUVERS precedes target acquisition; TARGET AND FIRE follows. Check one prompt at a time, no clipped text and readable targets. Rift is magenta, Lancer cyan, Bastion amber. Look for ship geometry disappearing or clipping on a switch. The other two ships keep fighting. Planet abilities remain locked. |
| 5. Heavy contact and retake | Reach the gunship, then take a death at an available checkpoint. Repeat the engagement after the CUT and continue on the withdrawal route. | HEAVY CONTACT and the checkpoint make the threat readable. Retake restores a playable checkpoint without replaying the intro or restarting the music. Clearing wave 1 alone must not begin the exit fade. Check that comms remain intelligible over music and weapons. |
| 6. Cross the boundary twice | On one run leave the gunship alive. On another destroy it first. Follow Command's withdrawal order and the corridor marker across the boundary on each run. Record from before the crossing to at least 22 seconds after it. | Either route completes once at the crossing. Note the TutorialEscaped event, visible marker, pursuers breaking off, and transition to Aftermath. Measure the whole 20-second music fade against the game audio. A wave-2 clear in an older fallback build cannot verify this path. Mark unavailable behavior as blocked with the build ID. |
| 7. Continue and replay | After a confirmed save past the tutorial, quit and Continue. Start a later New Game, take the offered tutorial skip, then separately test the cinematic skip on a run that plays the tutorial. | Continue returns to saved progress without repeating the tutorial or its music. Later New Game can skip directly to Aftermath with tutorial state applied. Skipping only the cinematic still enters the battle and brings the music in promptly with the quick fade. |

For each failure, save the timestamp, clip or screenshot, first reproducible step and observed behavior. Record the results in the engineering playtest log under docs/eng/PLAYTEST-*.md. Keep the first-play, subsequent skip, gunship-alive and gunship-destroyed results distinct. Report whether the 20-second tail was captured to completion.
