## Pack
- ffmpeg extracted all 150 frames (960×960) from the source MP4.
- A 120-frame window (source frames 30–149) was chosen as the lowest first/last-frame
  MSE in a search over window sizes 100–150, then subsampled to 64 frames.
- An 8-frame linear crossfade blends the last 8 packed frames toward the first 8.
- Each cell is resized to 256×256 (LANCZOS). Alpha = `clip((luma - 4) * 1.15)`
  where luma is `0.299R+0.587G+0.114B`.
- Loop MSE after the crossfade is still non-zero (~2040 vs ~2329 before); treat as an
  intended loop with a soft seam, not a perfect cycle.
