## Pack
- ffmpeg extracted all 150 frames (960×960) from the source MP4.
- A 100-frame window (source frames 26–125) was chosen as the lowest first/last-frame
  MSE in a search over window sizes 100–150, then subsampled to 64 frames.
- An 8-frame linear crossfade blends the last 8 packed frames toward the first 8.
- Each cell is resized to 256×256 (LANCZOS). Alpha = `max(R,G,B) * 1.05`, clipped.
- Loop MSE after the crossfade is still non-zero (~1367 vs ~2320 before); treat as an
  intended loop with a soft seam, not a perfect cycle. No hull or nose-cone mesh is
  visible in the packed sheet.
