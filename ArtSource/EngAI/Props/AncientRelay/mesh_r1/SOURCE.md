metadata; glTF's default unit is the metre. `source/base_basic_pbr.fbx` and
`source/base_basic_pbr.glb` agree on extents after import.

## Derived delivery (what to import)

Decimated, reoriented, pivoted and scaled in Blender 4.5.3. Source files were not
modified.

1. `DECIMATE` `COLLAPSE` (UVs kept, `use_collapse_triangulate=True`, no boundary dissolve)
   at ratio **0.53**, landing at **26,487 tris** / 13,177 unique verts (inside 24,000–27,500,
   strictly under 30,000). UVs stay in 0–1 (0 loops out of range; 290 islands). Topology
   stays watertight. Close-up checks of the split outer ring, core, radial supports and
   front stairs showed no new holes or broken gaps.
2. Rotated **+90° about Z** so the stair-fronted plinth and the ring face point **+X**
   (raw −Y → +X). +Z stays up. The mesh is symmetric on Y.
3. Uniformly scaled so height (`max Z − min Z`) is **10.0 m**, then dropped so min Z = 0
   and the origin is the ground-base centre (mid X = 0, mid Y = 0).

Nicholas's modelling board callouts 18.5 m tall and 24.0 m wide. Height was set to the
R-030 brief of about 10 m, not the board figure.

The 16:26 walkable-building note still listed #37 as on hold. This drop is the hero
**visual** mesh, including the board's front stairs and a carved (not perfectly flat)
courtyard. If the 180 cm pilot needs to walk onto the plinth, engineering can add a
simple collision slab; this file is not a modular walkable kit.

**FBX (`SM_AncientRelay.fbx`).** Exported with the repo's Unreal convention
(`apply_unit_scale=True`, `apply_scale_options='FBX_SCALE_UNITS'`, `axis_forward='-Z'`,
`axis_up='Y'`, face smoothing, tangents, triangulated). The file's `UnitScaleFactor` /
`OriginalUnitScaleFactor` are **100** (centimetres). Reimported in Blender, the mesh
measures **10.0000 m** tall at object scale 1.0, centred, min Z ≈ 0. Import with the
usual Interchange pipeline, uniform scale **1.0**; it should measure 1000.0 cm tall in
Unreal.

**GLB (`SM_AncientRelay.glb`).** Vertex values are in **metres** (glTF's default unit),
with `export_yup=false`, so the file itself is +Z up / +X forward (POSITION accessor
Z 0–10, X ±5.620, Y ±6.105) rather than the glTF-default Y-up convention. Prefer the
FBX with `UnitScaleFactor` 100 for Unreal. If an importer assumes glTF Y-up, it will
rotate the file; if it treats the numbers as metres with Z-up, use scale **1.0**; in
Unreal, if a glTF path treated the numbers as cm you would need scale **100**, which is
why the FBX is the one to import. The GLB embeds the OpenGL (glTF) normal, plus BC,
roughness, metallic and the cleaned emissive. Do not also use the GLB-embedded OpenGL
normal on top of `T_AncientRelay_N.png`.

## Textures

All delivery maps are 2048 × 2048 PNG.

| File | Role |
|---|---|
| `T_AncientRelay_BC.png` | Base Color, sRGB. Copied from `source/texture_diffuse.png`. |
| `T_AncientRelay_N.png` | Normal, **DirectX**. Built from `source/texture_normal.png` by inverting the green channel (OpenGL → DirectX). |
| `T_AncientRelay_ORM.png` | Packed masks, sRGB off: **R = AO** (solid 255; no AO in the pack), **G = roughness**, **B = metallic**. Byte-identical to `source/texture_pbr.png`. |
| `T_AncientRelay_E.png` | Emissive mask, sRGB. Lightly thresholded from `source/texture_emissive.png` (`max(R,G,B) <= 18 → 0`). Keeps the cyan core, beams and runes (190,818 pixels, 4.5495%); 36,526 residual near-black stone pixels were zeroed. |
| `contact_sheet.png` | Front +X (stairs), Side +Y, Back −X, Top +Z, 3/4 Hero, a scale comparison with a 180 cm pilot box at the foot of the +X stairs, and the BC / N / ORM / E swatches plus the modelling-reference and Rodin-input thumbs. Rendered in Blender 4.5.3 EEVEE (headless), with the cleaned emissive hooked up. |

`source/texture_normal.png` (and the normal embedded in both the raw and the derived GLB) is
**OpenGL** (Y+): it is the glTF normal, and the glTF 2.0 spec requires OpenGL tangent-space
normals. That matches how Rodin ships a glTF pack.

For Unreal, which expects **DirectX** (Y−), the delivery map `T_AncientRelay_N.png` has the
green channel inverted. Set N as a Normalmap (DirectX) and do **not** also use the
GLB-embedded OpenGL normal.
