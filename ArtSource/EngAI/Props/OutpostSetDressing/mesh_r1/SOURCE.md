# Outpost & landing-pad set dressing — mesh_r1 source

Route C procedural hard-surface. Blender 4.5.3 LTS, headless. **No AI 3D generator, no fal spend this round.**
Issue [#40](https://github.com/rthomas24/2026-epic-ai-megajam/issues/40). Branch `grok/assets-outpost-set-dressing-r1`.

Ten small props that furnish the Verdance and Cinder outposts and landing pads, after Nicholas's board
(`ArtSource/Reference/LandingPadSetDressing/Landing Pad Set Dressing Modeling Reference.png`, original, ChatGPT).
Per **R-043** these are **distant / out-of-reach dressing**, not walkable structures: each has simple `UCX_` boxes so the
pawn bumps into it, but nothing here is meant to be stood on or walked into.

**Total 15,588 visual tris** for all ten (UCX boxes are 12 tris each on top). Every prop is pivoted at the
ground-base centre (min Z = 0), +Z up, +X forward (screens, latches and dish face +X), object scale 1.

Small overshoots against the brief are trims and handles proud of the body (≤ 4 cm) and, on the comms dish, the dish
tilting 38° past the plinth (174.6 cm deep in X; the 160 cm brief is the dish diameter).

Per prop: `SM_Outpost_<Name>.blend` (editable), `.fbx` (Unreal), `.glb` (preview, metres, +Y up, OpenGL normal).
Shared material `M_OutpostProps`: `T_OutpostProps_BC / _N / _ORM / _E.png` (1K delivery, 2K masters in `source/textures_2k/`).

## Editable `.blend` per prop

Each `.blend` holds:
- `SM_Outpost_<Name>` — the visual mesh with **live, unapplied** modifiers: `Bevel` (angle limit 35°, 1 segment,
  4.5–6 mm, `harden_normals`, `clamp_overlap`) then `WeightedNormal` (`FACE_AREA`, weight 50, `keep_sharp`), on top of
  `shade_smooth` + `set_sharp_from_angle(30°)`.
- `SRC_SM_Outpost_<Name>` — **hidden** (viewport, render and view layer), modifier-free copy of the editable cage in the
  `Source` collection. Not exported.
- `UCX_SM_Outpost_<Name>_NN` — convex box colliders parented to the visual mesh (hidden from render).
- Textures linked relative (`//T_OutpostProps_*.png`), so the file opens with its maps from the delivery folder.

No `.blend1` backups are committed.

Wobble is 0% on nine props: every cylinder is six-sided (60° facets) so the 35° bevel catches each edge and nothing
shades soft. The comms dish bowl is deliberately 16 × 5 so it reads as a smooth parabola, not a hexagon, with a pale
reflector liner 4 mm proud inside it (the dark 4 cm shell edge left outside the liner is the rim lip). Bowl + liner
are the 14.7% wobble bucket on that prop and they shade-smooth under the 30° rule. The radial ribs follow the back of the
bowl, so none poke through the dish face.

## Units / export

- Authored in metres, Unreal axes (+X forward, +Z up).
- FBX: `apply_unit_scale=True`, `apply_scale_options=FBX_SCALE_UNITS`, `axis_forward='-Z'`, `axis_up='Y'`, triangulated,
  tangents, `mesh_smooth_type=OFF` (keeps the weighted / hardened custom normals), modifiers applied on export only.
- **`UnitScaleFactor = 100`** in every FBX (checked in the binary header). Unreal import uniform scale **1.0**.
- Mapping: Blender `(x, y, z)` m → Unreal `(100x, −100y, 100z)` cm.

- **BC:** dark gunmetal at **median sRGB 75** (p25 = 63; < 40 is only 0.7% of pixels), safety yellow, blue-grey polymer,
  hazard tape, bare metal, pale console plastic, plus unique tiles for the screens, keypad, warning sign and lamps.
  Meets the ≥ 55 dark-metal floor from the audit.
- **N:** DirectX (green flipped). Built from a height field: panel bodies proud, seams recessed with a smoothstep bevel
  profile, rivets indented with a lip, vents slatted, keycaps rounded. The > 24° bucket (8.6%) is those bevelled
  seam and rivet walls. The silhouette edges themselves are real geometry (live Bevel + hardened normals in the mesh).
- **ORM:** R = AO, G = roughness, B = metallic.
- **E:** screens, amber light bars, floodlamp faces, cyan / crimson LEDs; black elsewhere (median 0).

## How to rebuild

```bash
python3 source/make_textures.py                       # 2K masters -> source/textures_2k, 1K delivery -> .
blender -b --factory-startup --python source/build_outpost_props.py            # .blend/.fbx/.glb + build_results.json
blender -b --factory-startup --python source/render_contact_sheet.py -- .      # shots + contact_sheet.png
python3 source/render_contact_sheet.py .                                       # re-composite from source/shots only
```

## Unreal import

Static mesh, uniform scale 1.0, +X forward, +Z up, combine `UCX_` as custom convex collision. One material for all ten:
`T_OutpostProps_BC` (sRGB), `T_OutpostProps_N` (normal map, **do not flip green**, it is already DirectX),
`T_OutpostProps_ORM` (masks, sRGB off), `T_OutpostProps_E` (sRGB). Compatible with `M_TD_PropTextured`.

## Use in level

Non-walkable set dressing (Lead R-042: "distant and out of reach"). UCX is for blocking only; nothing here is a walk surface. `contact_sheet.png` is a 3000 px wide 192-colour PNG composited from `source/shots/` (shots are not committed).
