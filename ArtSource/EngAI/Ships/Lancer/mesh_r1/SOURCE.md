**FBX (`SM_Lancer.fbx`) — preferred for Unreal.** Exported with the repo's Unreal convention
(`apply_unit_scale=True`, `apply_scale_options='FBX_SCALE_UNITS'`, `axis_forward='-Z'`,
`axis_up='Y'`, face smoothing, tangents, triangulated). The file's `UnitScaleFactor` /
`OriginalUnitScaleFactor` are **100** (centimetres). Import with the usual Interchange pipeline,
uniform scale **1.0**; it should measure 524.0 cm long in Unreal.

**GLB (`SM_Lancer.glb`).** Vertex values are in **centimetres**, with `export_yup=false`, so the
file itself is +Z up / +X forward rather than glTF's default +Y up / +Z forward. glTF's official unit
is the metre: if an importer assumes metres, set uniform scale to **0.01**; if it treats the numbers as
cm (or you are in Unreal and want 524 uu), use scale **1.0**. The GLB embeds the OpenGL (glTF)
normal, plus BC, metallic-roughness and emissive.

## Normal convention

`source/texture_normal.png` (and the normal embedded in both the raw and the derived GLB) is
**OpenGL** (Y+): it is the glTF normal, B-channel is nearly 255 (outward Z), and the glTF 2.0 spec
requires OpenGL tangent-space normals. That matches how Rodin ships a glTF pack.

For Unreal, which expects **DirectX** (Y−), the delivery map `T_Lancer_N.png` has the green
channel inverted (`G' = 1 - G`). Red and blue are unchanged. This is the same convention used for
the accepted Drone mesh_r1 and the R-027 terrain sets. When importing the loose maps, set N as a
Normalmap (DirectX) and do **not** also use the GLB-embedded OpenGL normal.

## Lead-note compliance (honest)

The Lead's concept-gate notes for 3D: white must stay the main hull colour (squad colour ~30%);
engines need clean round nozzles; thin parts (nose spike, pylons, gun barrels) thickened enough
to survive at 40–60k tris.

- **White / cyan split.** Area-weighted albedo is about **22.7% white+off-white**,
  **20.9% cyan**, 40.2% dark mechanical / canopy. White is clearly the
  main hull colour in the renders and matches the approved r2 concept. Cyan sits close to the
  ~30% accent target and is not "mostly blue".
- **Engines.** One large, clean, round main nozzle at the tail plus two smaller lateral nozzles.
  Good attach points for exhaust effects.
- **Thin parts.** The nose spike is present and has thickness along most of its length; the tip
  is still a fine point (as in the concept) rather than a blunt club. Chin guns and wing pylons
  have volume. Topology is Rodin's auto-triangulation, not clean quads.
- **Proportions.** Scaled so length (X) is exactly 524 cm. Resulting size is
  **524.0 × 269.5 × 149.9 cm (L×W×H)** vs the brief
  524 × 318 × 164. Width is -48.5 cm (-15.2%),
  height -14.1 cm (-8.6%). A bit narrower and slightly shorter than
  the brief; uniform scale was not changed to force the brief width.
