## Raw source inspection (`source/base.glb`)

Inspected on 2026-11-13 with Blender 4.5.3 (headless). The file has no unit
metadata; glTF's default unit is the metre. The download was named
`null-interceptor-base-pbr.glb` and is byte-identical to `source/base.glb` (also
the `base.glb` inside `null-interceptor-base-pbr-fbx.zip`). Despite the "pbr"
filename, **the GLB contains no images, textures or material maps** — only a
mesh and a grey untextured Principled material (`baseColorFactor` 0.5,
`metallicFactor` 0.05, `roughnessFactor` 0.4). The accompanying zip contains
only `base.glb` and `base.fbx` (mesh-only). The Rodin viewer still
(`source/interceptor-viewer.png`) shows the same untextured clay mesh, with
Native / High and PBR 2K selected in the pack UI but not present in the
downloaded files.

The mesh does have a UV map (`UVMap`), so a later PBR pass can reuse this
derived mesh without a new unwrap.

**FBX (`SM_NullInterceptor.fbx`) — preferred for Unreal.** Exported with the repo's Unreal convention
(`apply_unit_scale=True`, `apply_scale_options='FBX_SCALE_UNITS'`, `axis_forward='-Z'`,
`axis_up='Y'`, face smoothing, tangents, triangulated). The file's `UnitScaleFactor` /
`OriginalUnitScaleFactor` are **100** (centimetres). Import with the usual Interchange pipeline,
uniform scale **1.0**; it should measure 660.0 cm long in Unreal.

**GLB (`SM_NullInterceptor.glb`).** Vertex values are in **centimetres**, with `export_yup=false`, so the
file itself is +Z up / +X forward rather than glTF's default +Y up / +Z forward. Accessor bounds are
symmetric ±330.0 / ±267.7 / ±124.0 (X/Y/Z), length 660.0 cm. glTF's official unit is the metre: if an
importer assumes metres, set uniform scale to **0.01**; if it treats the numbers as cm (or you are in
Unreal and want 660 uu), use scale **1.0**. The GLB has no textures (clay material only).

## Lead-note check: red-orange seams and the white 'eye' bar

**Not verifiable in this drop.** There are no albedo or emissive maps in the pack, so the
orange seams and the white eye cannot be checked on a texture. The clay mesh does have the
right forms in the right places: a circular eye socket on the pointed nose, chevron panel
breaks along the hooks and spine, a single rear engine bell, and two chin gun pods. A
second Rodin material pass (or a baked PBR pack re-download from the same job, if the
maps were generated and just not saved) is needed before this can be accepted as a
textured fleet ship. The UVs on this mesh are ready for that pass.

## Notes and issues

- The silhouette is faithful: hooked interceptor wings, a long pointed nose, a circular
  eye socket, two under-chin gun pods, a dorsal tail fin, a single rear engine. It reads
  as a future descendant of the same family as the Null Fighter and the player ships
  (chevron language, hooked planform, a nose 'eye'), even without paint (R-034).
- Compared with the approved concept, the hooks are a little thicker and the under-wing
  / chin pods read slightly heavier. The concept's hard orange seam lines and the bright
  white eye disc are not on the mesh because there are no maps.
- No rig, no sockets, no UCX collision — please add those on import if you want them. This
  drop was not run through `blender-ai-mesh-cleanup`.
- Topology is Rodin's auto-triangulation (not clean quads). Tris are already inside the
  6–10k cap.
