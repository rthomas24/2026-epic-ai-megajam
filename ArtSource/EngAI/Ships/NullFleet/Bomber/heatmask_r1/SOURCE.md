## Method

Per-vertex heat is computed from the engine-ready mesh in world space after the FBX import
(+X nose, +Z up; Blender shows the FBX in metres, which does not change the normalised
terms). Four geometric terms, each with a soft falloff, are combined with a screen blend
and three Laplacian smoothing passes:

1. **Bow / ram heating** — `max(0, dot(normal, +X))`, weighted toward the nose, and
   attenuated by a +X wind-exposure ray (a 3-ray cone, length 0.55 × ship length) so
   sheltered and trailing faces stay cool.
2. **Distance toward the nose** — a smoothstep on the normalised X position, plus a tighter
   nose-cap term on the front ~20%.
3. **Leading edges** — high curvature (face-normal deviation and sharp forward-facing
   edges) and local +X ridges (vertices further toward the nose than their neighbours),
   both weighted by forward facing, nose distance and exposure.
4. **Belly** — `max(0, dot(normal, −Z))`, stronger on the front half of the underside.

The 0–1 attribute is rasterized into the existing UV layout (barycentric interpolation per
triangle, overlapping writes keep the maximum) and dilated **32 px**, 8-connected, from a
separate coverage mask so a true zero on a cool island still dilates as zero rather than
being treated as empty. That is the same intent as a Cycles EMIT bake of a vertex-color
attribute with a 32 px Adjacent-Faces / Extend margin.

**Why not Cycles directly?** Cycles 4.5.3 on this box bakes a constant Emission shader on
these Rodin FBX meshes correctly, but a newly authored color attribute (POINT or CORNER,
BYTE or FLOAT, `ShaderNodeAttribute` or `ShaderNodeVertexColor`) evaluates to black, so
the EMIT bake of the attribute is empty. The rasterizer writes the same attribute into
the same UVs. The script is written so a Cycles path can be retried later.

The PNG is 8-bit linear grayscale (colour type 0, no gAMA chunk). Import in Unreal as a
mask with **sRGB off**.

## Import notes for the builders

- Path: `ArtSource/EngAI/Ships/NullFleet/Bomber/heatmask_r1/T_NullBomber_HeatMask.png`.
- Unreal: import as a mask / linear color, **sRGB off**. Sample as a scalar (the red
  channel, or any channel — they are identical). Do not pack it into ORM.
- Suggested hook: a descent-only emissive add, `lerp(black, orange-to-white-hot, mask)`,
  strength driven by entry speed / altitude. Leave `T_NullBomber_E.png` (engines and accent
  strips) alone.
- UVs must stay the `mesh_r1` `UVMap`. If the mesh is cleaned up or re-unwrapped, this
  mask will need a new bake (`heatmask_r2`).
- Preview only: `preview.png` is a look-dev still (EEVEE Next, AgX, compositor bloom),
  3/4 front and below so the nose, leading edges and belly all read. It is not an
  in-engine capture and is slightly hotter in the highlights than a careful material
  hook would be.
