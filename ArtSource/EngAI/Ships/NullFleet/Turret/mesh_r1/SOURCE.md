**FBX (`SM_NullTurret.fbx`) — preferred for Unreal.** Exported with the repo's Unreal convention
(`apply_unit_scale=True`, `apply_scale_options='FBX_SCALE_UNITS'`, `axis_forward='-Z'`,
`axis_up='Y'`, face smoothing, tangents, triangulated). The file's `UnitScaleFactor` /
`OriginalUnitScaleFactor` are **100** (centimetres). Reimported in Blender it measures
2.208 × 1.410 × 1.120 m, centred on the origin. Import with the usual Interchange
pipeline, uniform scale **1.0**; it should measure the brief length in Unreal.

**GLB (`SM_NullTurret.glb`).** Vertex values are in **centimetres**, with `export_yup=false`, so the
file itself is +Z up / +X forward rather than glTF's default +Y up / +Z forward. glTF's official unit
is the metre: if an importer assumes metres, set uniform scale to **0.01**; if it treats the numbers as
cm (or you are in Unreal and want the brief length in uu), use scale **1.0**. The GLB embeds the OpenGL (glTF)
normal, plus BC, metallic-roughness and emissive. Prefer the FBX for the engine import; Blender's default
glTF importer will swap Y/Z if it applies a second +Y-up conversion on top of `export_yup=false`.

## Lead-note check: red-orange seams and the white 'eye' bar

Checked on the 2K maps and on the derived-mesh renders (see `contact_sheet.png`).

- **Red-orange seams: present.** They read on the barrel trims, the dorsal chevron, the base ring and the housing insets, in both albedo and emissive. The emissive has about 58,500 orange pixels (1.39% of the 2K map). They are clearly visible in every contact-sheet view. The hull is a dark grey (mean RGB about 47, 30, 29), a little lighter than the carrier but still with good seam contrast.
- **White eye: present and clear.** The emissive has about 3,400 near-white pixels (0.081% of the map). On the mesh it reads as a bright lamp between the twin barrels, in the same place as the concept, and holds up in the front and 3/4 views.

## Notes and issues

- The silhouette is very close to the approved concept: twin barrels, a circular stepped base, a dorsal chevron, and a white eye between the guns. It clearly shares the Null / Triad family language as asked in R-034.
- Small departures: the housing is a slightly softer block than the concept's harder panel breaks; the eye window is a little smaller. Nothing that breaks the read.
- **Flag — triangle budget:** 8,820 tris is over the 2–4k brief. A 4k-topology redo was skipped as too costly, so the Clean Topology export was kept. It is under the ~20k decimate cutoff used for fleet craft.
- No rig, no sockets, no UCX collision — please add those on import if you want them (the placeholder has `Muzzle_0` / `Muzzle_1`). This drop was not run through `blender-ai-mesh-cleanup`.
- Topology is Rodin's auto-triangulation (not clean quads).
- No heat-glow mask was baked for the turret (masks were requested for the ships only).

## Normal convention

`source/texture_normal.png` (and the normal embedded in both the raw and the derived GLB) is
**OpenGL** (Y+): it is the glTF normal, B-channel is nearly 255 (outward Z), and the glTF 2.0 spec
requires OpenGL tangent-space normals. That matches how Rodin ships a glTF pack.

For Unreal, which expects **DirectX** (Y−), the delivery map `T_T_NullTurret_N.png` has the green
channel inverted (`G' = 1 - G`). Red and blue are unchanged. This is the same convention used for
the accepted Drone mesh_r1, the player-ship mesh_r1, the Warden mesh_r1 and the earlier Null fleet
meshes. When importing the loose maps, set N as a Normalmap (DirectX) and do **not** also use the
GLB-embedded OpenGL normal.
