## Normal convention (moss only)

The default export does not document whether `NRM` is OpenGL or DirectX. Method used on 2026-11-13:

1. Calibration on `Verdance_Soil`, whose Unreal/UEFN README states the `N` map is DirectX. A wraparound central-difference normal was computed from that set's height (`H`) map: `dx = height[x+1] - height[x-1]`, `dy = height[y+1] - height[y-1]` (image space, rows increase downward). Strength and the signs of X and Y were swept; the best correlation with the soil `N` map was **strength = 16, x_sign = -1, y_sign = -1** (Pearson correlation R = 0.848, G = 0.862, B = 0.815). Those parameters are therefore the DirectX-calibrated height-to-normal predictor.
2. The same predictor was applied to the moss `DISP` map and correlated with moss `NRM`. The green channel was **anti-correlated** with the DirectX predictor (G = −0.714; R still matched at +0.731). Flipping the predictor's green channel raised the green correlation to +0.714.
3. Conclusion: moss `NRM` is **OpenGL**. For the delivery map `T_Verdance_moss_N.png`, the green channel was inverted (`G' = 1 - G`) so the map is **DirectX**, matching the other eight Unreal/UEFN exports. Red and blue were left unchanged.

MaterialX's default `normalmap` node (present in the source `.mtlx`, with no `space` override) is also consistent with an OpenGL source normal.
