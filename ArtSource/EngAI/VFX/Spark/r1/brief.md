# Spark r1 (brief)

R-027 item #7 add-on ("plus a … spark texture if cheap"). Procedural, not a fal
generation, so it cost nothing and the sprite is clean for Niagara.

## What this round delivers
- `T_VFX_Spark.png`: 1024×1024 RGBA. A bright slightly-warm point core, a long
  horizontal streak, a shorter vertical flare, and a soft bloom. Rotate / tint in
  the material for spark bursts.
