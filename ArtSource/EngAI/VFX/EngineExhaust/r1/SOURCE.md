## Pack
- ffmpeg extracted all 150 frames (960×960) from the source MP4.
- A residual thruster rim was still visible on the far left of the clip. Each
  source frame was cropped 128 px from the left and right-padded with black
  (back to 960×960) before packing, so the sheet is flame-only. The source MP4
  is untouched and still shows the rim.
- A 130-frame window (source frames 10–139) was chosen as the lowest first/last-frame
  MSE in a search over window sizes 100–150, then subsampled to 64 frames.
- An 8-frame linear crossfade blends the last 8 packed frames toward the first 8.
- Each cell is resized to 256×256 (LANCZOS). Alpha = `max(R,G,B) * 1.05`, clipped.
- Loop MSE after the crossfade is still non-zero (~1970 vs ~1318 before on the
  pre-crossfade ends). Treat as an intended loop with a soft seam, not a perfect cycle.
