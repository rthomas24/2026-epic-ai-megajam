# Soft radial glow r1 (brief)

R-027 item #7 add-on ("plus a soft radial glow … if cheap"). Procedural, not a
fal generation, so it cost nothing and the falloff is perfectly smooth and tintable.

## What this round delivers
- `T_VFX_Glow.png`: 2048×2048 RGBA. White RGB with a soft circular core and a wider
  halo; alpha carries the same falloff. Tint in the material for fire, shields, hits, etc.
