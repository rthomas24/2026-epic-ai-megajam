# Triad Drift VFX starter kit

Four original, texture-free **material prototypes**, plus twelve squad-colored instances.
These are additive plane materials, not Niagara systems or gameplay components.

Open `preview.html` for the animated art-direction review. It has palette selection,
brightness, pause and pulse restart. Browser visuals approximate the shaders; they are
not proof of Unreal rendering parity.

## Build after claims are published

In UE 5.9 with PythonScriptPlugin enabled for the process, run `build_unreal.py`.
The Lead owns execution. It creates 16 assets only in
`/Game/TriadDrift/VFX/StarterKit`: four `M_TD_*` masters and three `MI_TD_*`
variants per effect. Existing assets cause an early refusal; no assets are overwritten.
No map, shared asset, gameplay file, project config or class interface is modified.

Example process invocation (Lead only):

```powershell
& '<UE_5.9>/Engine/Binaries/Win64/UnrealEditor-Cmd.exe' '<project>.uproject' `
  -unattended -nullrhi -EnablePlugins=PythonScriptPlugin `
  -run=pythonscript '-script=<absolute path>/build_unreal.py'
```

Use two perpendicular planes for engine exhaust (U=0 nozzle, U=1 tail), or a
camera-facing plane for flashes and impacts. Avoid putting an impact plane coplanar
with a hull; offset it a few centimeters along the hit normal. No collision needed.
`/Engine/BasicShapes/Plane` is a suitable temporary engine-provided preview surface.

## Parameters

| Parameter | Use |
|---|---|
| Color / Intensity | Squad tint and HDR brightness; keep saturated detail readable |
| Length / Width | Trail UV proportions; use component scale for world-space size |
| Speed | Trail pulse travel rate |
| Softness | Trail edge falloff |
| Lifetime | Flash/impact fade duration in seconds |
| StartTime | World time at spawn (must use the same clock as the Time material node) |
| PreviewLoop | `1`: continuous inspection; `0`: one shot using StartTime |

Runtime integration must set `PreviewLoop=0`, `StartTime` and `Lifetime` on a dynamic
material instance, then remove the transient visual component after Lifetime.
The engine trail is continuous and does not use Lifetime. Those integration choices
belong to Ryan; this kit makes no assumptions about his final presentation classes.
The provided material instances deliberately loop for convenient inspection.

Attachment orientation stays configurable: Unreal ship local +X is forward, -Y
left and +Y right; exhaust points -X. Align the trail plane's increasing U axis
with exhaust direction. Rotate billboard planes to face the camera or hit normal.
Proposed Lancer art sockets are `Muzzle_Primary_L/R`, `Muzzle_Secondary_L/R_01..04`,
`Thruster_L/R`, `Ability_Overdrive` and `Ability_EMP`. These are authoring proposals
only, not finalized gameplay APIs; no socket lookup or fixed offsets are embedded.

## Budget and limits

No texture fetches, dynamic lights, mesh generation, simulation, ribbons or collision.
Each visible plane is one translucent draw: pool and batch in the eventual emitter;
avoid many overlapping planes at screen-filling size. Distance cull small flashes.
Shield lattice is a stylized procedural interference pattern, not an exact hex grid.
Depth intersection softening and Niagara emitters are follow-up work after in-engine review.

Source-only delivery: Python syntax and shader math can be checked without Unreal.
Native assets and shader compilation require the Lead's serial UE verification and
have **not** been generated by this worker.
